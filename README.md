# Ternura e Afago — mensagens

Vídeos verticais (9:16) de bom dia, boa tarde e boa noite com mensagens de fé, e as skills do Claude Code usadas para produzi-los.

- `videos/` — vídeos finalizados (`originais/` = clipes de partida)
- `imagens/` — imagens de partida
- `logo/` — logo da página (quadrada e redonda)
- `skills/boa-noite` — imagem → vídeo animado de boa noite (copiar para `~/.claude/skills/`)
- `skills/terror-short` — skill de shorts de terror
- `scripts/` — scripts de texto sobre vídeo (bom dia / boa tarde) e da logo
